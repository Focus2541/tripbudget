# ✈️ TripBudget — คำนวณค่าใช้จ่ายเที่ยวต่างประเทศ

เว็บแอปวางแผนและบันทึกค่าใช้จ่ายเที่ยวต่างประเทศ ใช้บนมือถือได้เหมือนแอป ทำงานออฟไลน์ได้ ไม่ต้องมีเซิร์ฟเวอร์ ข้อมูลเก็บในเครื่องผู้ใช้เท่านั้น

## ฟีเจอร์

- **หลายทริป** — สร้าง แก้ไข ทำสำเนา ลบ และ**เปรียบเทียบ**ทริป (รวม / ต่อคน / ต่อวัน)
- **ตั๋วเครื่องบิน & ก่อนเดินทาง** — ตั๋วต่อคน สัมภาระ ประกัน วีซ่า ซิม ฯลฯ
- **ที่พัก** — หลายแห่ง แต่ละแห่งใช้สกุลเงินและเรทของตัวเอง
- **ค่าใช้จ่ายรายวัน** — หมวดหมู่ วิธีจ่าย หมายเหตุ ค้นหา/กรอง และ**เพิ่มซ้ำหลายวัน**ในครั้งเดียว
- **หลายสกุลเงินในทริปเดียว** — แต่ละรายการเลือกสกุลเงินเองได้ (เหมาะกับทริปหลายประเทศ)
- **เก็บเรท ณ วันที่จ่าย** — แต่ละรายการจำเรทของตัวเอง ยอดย้อนหลังไม่เปลี่ยนตามเรทใหม่ (แก้เป็นเรทร้านแลกเงินจริงได้)
- **เรทเงินอัตโนมัติ** — ดึงเรทกลางตลาดจาก open.er-api.com ทุก 6 ชม. มีเรทสำรองในเครื่องเมื่อออฟไลน์
- **หารเงินกับเพื่อน** — ระบุใครจ่าย หารกับใคร แล้วคำนวณว่าใครต้องโอนให้ใคร (โอนน้อยครั้งที่สุด) คัดลอกไปส่ง LINE ได้
- **เทมเพลตงบตามประเทศ** — ประมาณงบ 3 ระดับ (ประหยัด/กลาง/สบาย) ตามจำนวนวันและจำนวนคน
- **ปฏิทิน** — ดูยอดใช้จ่ายแต่ละวันของทริป
- **สรุป** — แยกหมวด / วิธีจ่าย / รายวัน / รายคน, เตือนเมื่อใกล้หรือเกินงบ, บอกงบที่ใช้ได้ต่อวัน
- **ใบเสร็จ** — ถ่ายรูปแนบได้ ย่อรูปอัตโนมัติและเก็บใน IndexedDB (ไม่ทำให้พื้นที่เต็มเร็ว)
- **Export** — CSV เปิดใน Excel/Google Sheets, สำรอง/กู้คืนข้อมูลทั้งหมด (รวมรูป) เป็นไฟล์ JSON
- **PWA** — ติดตั้งลงหน้าจอหลัก Android/iPhone, ใช้งานออฟไลน์ได้

## ไฟล์ในโปรเจกต์

```
index.html      ตัวแอปทั้งหมด (HTML + CSS + JS ในไฟล์เดียว)
manifest.json   ข้อมูลแอปสำหรับติดตั้ง (ชื่อ ไอคอน สี)
sw.js           Service worker สำหรับใช้งานออฟไลน์
icons/          ไอคอนแอป
.nojekyll       บอก GitHub Pages ไม่ต้องประมวลผลไฟล์
```

## ขึ้น GitHub Pages (ทำบนมือถือได้)

1. เข้า [github.com](https://github.com) → กด **+** → **New repository** → ตั้งชื่อ เช่น `tripbudget` → เลือก **Public** → **Create repository**
2. กด **uploading an existing file** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวมโฟลเดอร์ `icons`) → **Commit changes**
   - ถ้าอัปโหลดผ่านมือถือ: แตกไฟล์ zip ก่อน แล้วอัปโหลดทีละไฟล์ สำหรับไอคอนให้พิมพ์ชื่อไฟล์เป็น `icons/ชื่อไฟล์` ตอนสร้างไฟล์
3. ไปที่ **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
4. รอ 1–2 นาที แอปจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/tripbudget/`

### ติดตั้งเป็นแอปบน Android
เปิดลิงก์ใน Chrome → เมนู ⋮ → **ติดตั้งแอป** / **เพิ่มลงในหน้าจอหลัก** (หรือกดเมนู ⋮ ในแอป → 📲 ติดตั้งเป็นแอป)

## อัปเดตเวอร์ชัน

เมื่อแก้ `index.html` แล้วอัปโหลดใหม่ ให้เปลี่ยนเลขใน `sw.js` บรรทัด `const CACHE = 'tripbudget-v3.0.0'` ด้วย (เช่นเป็น `v3.0.1`) ผู้ใช้จะได้เวอร์ชันใหม่ตอนเปิดแอปครั้งถัดไป

## ข้อมูลและความเป็นส่วนตัว

- ข้อมูลทั้งหมดอยู่ใน browser ของเครื่องนั้นเท่านั้น ไม่มีการส่งขึ้นเซิร์ฟเวอร์
- การล้างข้อมูลเว็บ/แคชของ browser จะทำให้ข้อมูลหาย → กด **⋮ → สำรองข้อมูล** เป็นระยะ แล้วเก็บไฟล์ไว้ใน Google Drive
- ย้ายเครื่อง: สำรองจากเครื่องเก่า → **⋮ → กู้คืนข้อมูล** ในเครื่องใหม่
- ข้อมูลจากเวอร์ชันก่อน (v2) ในเครื่องเดียวกันจะถูกย้ายมาอัตโนมัติ และไฟล์สำรองแบบเก่าก็นำเข้าได้

## หมายเหตุ

- เรทเป็นเรทกลางตลาด เรทร้านแลกเงิน/บัตรเครดิตจริงจะต่างเล็กน้อย — แก้เรทในแต่ละรายการได้
- ตัวเลขในเทมเพลตงบเป็นค่าประมาณคร่าวๆ สำหรับวางแผนเท่านั้น
- เรทเงินจาก [ExchangeRate-API](https://www.exchangerate-api.com) (open access)
