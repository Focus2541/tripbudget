# 🧳 TripBudget

เว็บแอปวางแผนทริป รวม 3 อย่างไว้ในทริปเดียว: **เตรียมของ + งบประมาณ + เคล็ดลับไปต่างประเทศครั้งแรก**
ติดตั้งลงมือถือได้เหมือนแอป ใช้งานออฟไลน์ได้ ข้อมูลเก็บในเครื่องผู้ใช้เท่านั้น

🔗 **เปิดใช้งาน:** https://focus2541.github.io/tripbudget/

## ฟีเจอร์

**ทริป**
- ชื่อทริป, ประเภท (เที่ยวพักผ่อน / ธุระ / ค้างบ้านญาติ / ต่างประเทศ / กำหนดเอง), วันเดินทาง, จำนวนวัน, ประเทศปลายทาง
- ประเทศปลายทางกำหนดสกุลเงิน ชนิดปลั๊ก แรงดันไฟ และเบอร์ฉุกเฉินให้อัตโนมัติ
- ดึงเรทแลกเงินสดตอนสร้างทริป แก้ตัวเลขเองได้ (ใส่เรทร้านแลกเงินจริงได้)
- นับถอยหลังถึงวันเดินทาง

**เตรียมของ**
- ลิสต์ของตามประเภททริป แบ่งตามหมวด ติ๊กได้ เพิ่ม/แก้/ลบได้
- ของที่ใช้ต่อวัน (เสื้อ ชุดชั้นใน ถุงเท้า) คูณจำนวนวันให้อัตโนมัติ
- แก้เทมเพลตหลักได้ (ทุกทริป / เที่ยว / ธุระ / ค้างบ้านญาติ / ต่างประเทศ) และรีเซ็ตกลับค่าเริ่มต้นได้
- ปลั๊กแปลงหัวบอกชนิดที่ต้องใช้ตามประเทศปลายทาง

**งบประมาณ**
- ตั้งงบตามหมวด: ตั๋ว, ที่พัก, อาหาร (ต่อวัน), เดินทางในพื้นที่, ช้อปปิ้ง, อื่นๆ
- บันทึกรายจ่ายเป็นสกุลเงินท้องถิ่น แปลงเป็นบาทอัตโนมัติ แต่ละรายการจำเรทตอนบันทึก
- แสดงงบรวม / ใช้ไป / คงเหลือ, เตือนเมื่อใกล้หรือเกินงบ, บอกค่าอาหารที่เหลือใช้ได้ต่อวัน
- แนบรูปใบเสร็จได้

**หารเงิน / ปฏิทิน / เปรียบเทียบ**
- ใส่ชื่อผู้ร่วมทริป แล้วตอนบันทึกรายจ่ายเลือกว่าใครจ่ายและหารกับใคร แอปคำนวณว่าใครต้องโอนให้ใคร (จำนวนครั้งน้อยที่สุด) คัดลอกไปส่ง LINE ได้
- ดูรายจ่ายแบบปฏิทินตามวันของทริป แตะวันเพื่อดูรายการ
- เปรียบเทียบหลายทริป: งบ รายจ่ายจริง ต่อคนต่อวัน แยกหมวด

**เคล็ดลับต่างประเทศ** (ขึ้นอัตโนมัติเมื่อประเทศปลายทางไม่ใช่ไทย)
- เอกสาร/วีซ่า, เงิน/ธนาคาร, ของต้องเตรียม, สนามบิน, ฉุกเฉิน — ติ๊กเป็นเช็กลิสต์ได้

**ส่วนที่เชื่อมกัน**
- ติ๊กของที่ต้องซื้อ (eSIM ประกัน ปลั๊กแปลง ของฝาก) แล้วแอปถามว่าจะบันทึกเป็นรายจ่ายไหม
- เปลี่ยนทริปเป็นต่างประเทศ แอปถามว่าจะเพิ่มของสำหรับต่างประเทศเข้าลิสต์ไหม

**ข้อมูล**
- สำรอง / กู้คืนเป็นไฟล์ `.json` (รวมเทมเพลตและรูปใบเสร็จ)
- ข้อมูลจาก TripBudget เวอร์ชันก่อนในเครื่องเดียวกันย้ายมาให้อัตโนมัติ และไฟล์สำรองแบบเก่ากู้คืนได้

**v5: ใช้ระหว่างทริป**
- 🆘 **การ์ดฉุกเฉินออฟไลน์** (ปุ่ม SOS บนแถบบน): เบอร์ฉุกเฉินของประเทศ ที่อยู่ที่พัก (กด "แสดงคนขับ" เป็นตัวใหญ่) ข้อมูลแพ้ยา เบอร์ญาติ ประกัน สถานทูต และประโยคขอความช่วยเหลือภาษาท้องถิ่น 12 ภาษา
- 🗓️ **แผนเที่ยวรายวัน** (แท็บ "แผน"): ใส่เวลา สถานที่ กดนำทางด้วย Google Maps
- 📎 **ตั๋วและใบจอง**: เก็บรูปหรือ PDF ไว้ในเครื่อง เปิดดูได้แม้ไม่มีเน็ต
- 🔔 **สิ่งที่ต้องทำ**: แอปคำนวณว่าต้องกรอกฟอร์ม ยื่นวีซ่า ซื้อประกัน เช็กอิน แพ็กของ วันไหน กด 📅 ใส่ Google Calendar ได้ และแจ้งเตือนเมื่อเปิดแอป
- 🔍 **สแกนยอดจากรูปใบเสร็จ** (ต้องใช้อินเทอร์เน็ต)
- 📤 **แชร์ทริปให้เพื่อน**: ส่งไฟล์ทาง LINE เพื่อนกู้คืนในแอปได้
- 💾 **เตือนสำรองข้อมูล** เมื่อไม่ได้สำรองเกิน 14 วัน
- 🧠 **ทริกเอาตัวรอด** ในหน้าเคล็ดลับ
- 🌤️ **ฤดูกาลและอากาศ** 23 ประเทศ × 12 เดือน ตามช่วงที่ไป (หิมะ ซากุระ ฤดูฝน ไต้ฝุ่น เทศกาล) พร้อมของที่ควรพก กดเพิ่มเข้าลิสต์ได้
- 🛂 **คุยกับ ตม.**: คำถามที่ ตม. มักถาม 10 ข้อ พร้อมคำอ่านภาษาไทย คำตอบภาษาอังกฤษที่เติมข้อมูลทริปให้ ฟังเสียงซ้อม และโหมดตัวใหญ่ยื่นให้เจ้าหน้าที่อ่าน

**v5.5: เงินระหว่างทริป**
- 👛 **กระเป๋าเงิน**: เลือกตอนบันทึกรายจ่ายว่าจ่ายด้วย 💵 เงินสด / 💳 บัตร / 🚃 IC card แอปบอกเงินสดสกุลท้องถิ่นที่เหลือ และปุ่ม "นับเงินจริง" ปรับยอดให้ตรง
- 💱 **บันทึกการแลกเงินจริง**: ที่ไหน จ่ายกี่บาท ได้เท่าไหร่ แอปคิดเรตเฉลี่ยจริงของทริป แล้วใช้คิดรายจ่ายเงินสด (ปิดได้ในตั้งค่า)
- 📅 **งบรายวัน**: วันนี้ใช้ไปกี่ % ของงบวัน เกินแล้วขึ้นสีเตือน และบอกว่าวันที่เหลือใช้ได้วันละเท่าไหร่
- 🇹🇭 **สถานทูตไทย** ตามประเทศในการ์ดฉุกเฉิน, ปุ่มแสดงเลขกรมธรรม์ตัวใหญ่, ที่อยู่ที่พักภาษาท้องถิ่นโชว์ตัวใหญ่ให้แท็กซี่
- 🇯🇵 **ญี่ปุ่น**: ติ๊ก Tax-free พร้อมเตือนเก็บใบเสร็จ (กติกาคืนภาษีแบบใหม่ 1 พ.ย. 2569) และบันทึกเติมเงิน/ยอดคงเหลือ IC card
- 🖼️ **สรุปทริปเป็นภาพ**: บันทึกรูปหรือแชร์ไป LINE
- 📷 **ปุ่มแปลเมนู** และให้แอปอื่นเพิ่มรายจ่ายเข้าทริปได้ (ดูหัวข้อด้านล่าง)

## ให้แอปอื่นเพิ่มรายจ่าย (เช่น แอปแปลเมนู)

แอปที่อยู่ใต้ `focus2541.github.io` ใช้ localStorage ร่วมกัน คุยกันผ่าน 2 key (เปิด/ปิดได้ใน ⚙️ ตั้งค่า → เชื่อมกับแอปอื่น)

**`tb_active`** — TripBudget เขียน แอปอื่นอ่านอย่างเดียว (ทริปที่เปิดอยู่ ไม่มียอดเงิน)
```json
{"v":1,"app":"TripBudget","tripId":"abc123","name":"ญี่ปุ่น","country":"JP","currency":"JPY",
 "rate":0.23,"cashRate":0.2222,"day":2,"days":5,
 "cats":["ticket","hotel","food","transport","shopping","other"],"pays":["cash","card","ic"],"updatedAt":"2026-11-03T05:00:00Z"}
```
ถ้าไม่มี key นี้ แปลว่ายังไม่มีทริป หรือผู้ใช้ปิดการเชื่อม

**`tb_inbox`** — แอปอื่นเขียน: อาร์เรย์ JSON ของรายจ่าย ให้อ่านของเดิมแล้วต่อท้าย (ห้ามเขียนทับ)
```json
[{"id":"menu-1730610000000-ab12","source":"menu","name":"ราเมงทงคตสึ","amount":1200,"curr":"JPY",
  "cat":"food","pay":"cash","note":"","tripId":"abc123","day":2,"taxFree":false,"at":"2026-11-03T05:00:00Z"}]
```
| field | จำเป็น | ความหมาย |
|---|---|---|
| `id` | ควรมี | รหัสไม่ซ้ำ กันเพิ่มซ้ำ |
| `amount` | ✓ | ยอดเงิน > 0 |
| `curr` | ✓ | รหัสสกุลเงิน เช่น `JPY` `THB` (ต้องเป็นสกุลที่แอปรู้จัก) |
| `name` | | ชื่อรายการ (สูงสุด 80 ตัวอักษร) |
| `cat` | | `food` `transport` `shopping` `other` `ticket` `hotel` (ไม่ใส่ = `food`) |
| `pay` | | `cash` `card` `ic` (`ic` ใช้ได้เฉพาะทริปญี่ปุ่น) |
| `tripId` | | จาก `tb_active` ไม่ใส่ = ทริปที่เปิดอยู่ |
| `day` | | วันที่ของทริป (0 = ก่อนเดินทาง) ไม่ใส่ = วันนี้ |
| `source` | | ชื่อแอป เช่น `menu` แสดงเป็น "📥 จากแปลเมนู" |
| `note`, `taxFree`, `at` | | หมายเหตุ / Tax-free / เวลาที่สร้าง |

TripBudget ดึงรายการเข้าเมื่อเปิดแอป กลับมาที่แอป หรือเมื่อ `tb_inbox` เปลี่ยน แล้วลบรายการที่นำเข้าแล้วออก รายการที่ข้อมูลไม่ถูกต้องจะถูกทิ้ง
ลิงก์ปุ่ม "📷 แปลเมนู" ตั้งที่ `MENU_APP_URL` ใน `version.js` แอปจะเปิดด้วย `?from=tripbudget&trip=<id>&curr=<สกุลเงิน>&country=<ประเทศ>`

## อัปเดตข้อมูลประเทศ

ข้อมูลประเทศทั้งหมดอยู่ในไฟล์ `countries.js` แยกจากตัวแอป แก้ได้โดยไม่ต้องแตะ `index.html`
- `COUNTRIES` สกุลเงิน ปลั๊ก แรงดันไฟ เบอร์ฉุกเฉิน ภาษา
- `ENTRY` วีซ่าและฟอร์มเข้าประเทศ (`w` = กรอกได้ล่วงหน้ากี่วัน, `lead` = เตือนล่วงหน้ากี่วัน)
- `RULES` กฎและข้อห้าม
- `TRAVEL`, `HOTEL_SITES`, `TICKET_SITES` เว็บจองที่พักและเดินทาง
- `PHRASES` ประโยคขอความช่วยเหลือ
- `SEASONS` ฤดูกาล อากาศ และของแนะนำรายเดือน
- `EMBASSY` เบอร์สถานทูต/กงสุลไทย (`h` ฉุกเฉิน, `t` สำนักงาน)

แก้ใน GitHub ได้เลย (เปิดไฟล์ → ✏️) แล้วเปลี่ยนเลข `APP_VERSION` ใน `version.js` ด้วย

## ไฟล์

```
index.html      ตัวแอป (HTML + CSS + JS)
version.js      เลขเวอร์ชันแอป + ลิงก์ส่งความเห็น (แก้ที่นี่ทุกครั้งที่อัปเดต)
apps-script/    โค้ด Google Apps Script รับความเห็นและสถิติ
countries.js    ข้อมูลประเทศ แก้เพื่ออัปเดตกฎ/เอกสาร/เว็บจอง
manifest.json   ข้อมูลสำหรับติดตั้งเป็นแอป
sw.js           Service worker สำหรับใช้งานออฟไลน์
icon.svg        ไอคอนแอป
icon-192.png    ไอคอนสำรองสำหรับ Android รุ่นที่ไม่รองรับ SVG
icon-512.png
```

## ติดตั้งบน Android

เปิดลิงก์ใน Chrome → เมนู ⋮ → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก** (หรือกด ⋮ ในแอป → 📲 ติดตั้งเป็นแอป)

## ความเห็นและสถิติการใช้งาน

ผู้ใช้กด ⋮ → ส่งความเห็น ได้ ส่วนสถิติการใช้งานนับแบบไม่ระบุตัวตน ส่งวันละครั้ง (ปิดได้ในตั้งค่า) ทั้งสองอย่างส่งเข้า Google Sheet ผ่าน Google Apps Script
วิธีติดตั้งอยู่ใน `apps-script/README.md` แล้วใส่ลิงก์ใน `FEEDBACK_URL` ของ `version.js`

## อัปเดตเวอร์ชัน

แก้ไฟล์ไหนก็ตาม ให้เปลี่ยนเลข `self.APP_VERSION` ใน `version.js` ด้วย (ไฟล์เดียว) แอปของทุกคนจะขึ้นแถบ "มีอัปเดต กดเพื่อโหลดใหม่" และ service worker จะสร้างแคชชื่อ `tripbudget-v<เลขเวอร์ชัน>` ใหม่ให้เอง ไม่ต้องแก้ `sw.js`

## หมายเหตุ

- การล้างข้อมูลเว็บของ Chrome จะทำให้ข้อมูลหาย กด ⋮ → สำรองข้อมูล เป็นระยะ แล้วเก็บไฟล์ไว้ใน Google Drive
- เรทเงินเป็นเรทกลางตลาดจาก [ExchangeRate-API](https://www.exchangerate-api.com) เรทร้านแลกเงินจริงจะต่างเล็กน้อย
- เคล็ดลับและข้อมูลประเทศเป็นคำแนะนำทั่วไป กฎวีซ่าและสายการบินเปลี่ยนได้ ควรเช็กจากแหล่งทางการก่อนเดินทาง
