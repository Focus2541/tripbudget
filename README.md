# 🧳 TripBudget

เว็บแอปวางแผนทริป รวม 3 อย่างไว้ในทริปเดียว: **เตรียมของ + งบประมาณ + เคล็ดลับไปต่างประเทศครั้งแรก**
ติดตั้งลงมือถือได้เหมือนแอป ใช้งานออฟไลน์ได้ ข้อมูลเก็บในเครื่องผู้ใช้เท่านั้น

🔗 **เปิดใช้งาน:** https://focus2541.github.io/tripbudget/

## ฟีเจอร์

**ทริป**
- ชื่อทริป, ประเภท (เที่ยวพักผ่อน / ธุระ / ค้างบ้านญาติ / ต่างประเทศ / กำหนดเอง), วันเดินทาง, จำนวนวัน, ประเทศปลายทาง
- ประเทศปลายทางกำหนดสกุลเงิน ชนิดปลั๊ก แรงดันไฟ และเบอร์ฉุกเฉินให้อัตโนมัติ
- ดึงเรทแลกเงินสดตอนสร้างทริป แก้ตัวเลขเองได้ (ใส่เรทร้านแลกเงินจริงได้)
- นับถอยหลังถึงวันเดินทาง

**เตรียมของ**
- ลิสต์ของตามประเภททริป แบ่งตามหมวด ติ๊กได้ เพิ่ม/แก้/ลบได้
- ของที่ใช้ต่อวัน (เสื้อ ชุดชั้นใน ถุงเท้า) คูณจำนวนวันให้อัตโนมัติ
- แก้เทมเพลตหลักได้ (ทุกทริป / เที่ยว / ธุระ / ค้างบ้านญาติ / ต่างประเทศ) และรีเซ็ตกลับค่าเริ่มต้นได้
- ปลั๊กแปลงหัวบอกชนิดที่ต้องใช้ตามประเทศปลายทาง

**งบประมาณ**
- ตั้งงบตามหมวด: ตั๋ว, ที่พัก, อาหาร (ต่อวัน), เดินทางในพื้นที่, ช้อปปิ้ง, อื่นๆ
- บันทึกรายจ่ายเป็นสกุลเงินท้องถิ่น แปลงเป็นบาทอัตโนมัติ แต่ละรายการจำเรทตอนบันทึก
- แสดงงบรวม / ใช้ไป / คงเหลือ, เตือนเมื่อใกล้หรือเกินงบ, บอกค่าอาหารที่เหลือใช้ได้ต่อวัน
- แนบรูปใบเสร็จได้

**หารเงิน / ปฏิทิน / เปรียบเทียบ**
- ใส่ชื่อผู้ร่วมทริป แล้วตอนบันทึกรายจ่ายเลือกว่าใครจ่ายและหารกับใคร แอปคำนวณว่าใครต้องโอนให้ใคร (จำนวนครั้งน้อยที่สุด) คัดลอกไปส่ง LINE ได้
- ดูรายจ่ายแบบปฏิทินตามวันของทริป แตะวันเพื่อดูรายการ
- เปรียบเทียบหลายทริป: งบ รายจ่ายจริง ต่อคนต่อวัน แยกหมวด

**เคล็ดลับต่างประเทศ** (ขึ้นอัตโนมัติเมื่อประเทศปลายทางไม่ใช่ไทย)
- เอกสาร/วีซ่า, เงิน/ธนาคาร, ของต้องเตรียม, สนามบิน, ฉุกเฉิน — ติ๊กเป็นเช็กลิสต์ได้

**ส่วนที่เชื่อมกัน**
- ติ๊กของที่ต้องซื้อ (eSIM ประกัน ปลั๊กแปลง ของฝาก) แล้วแอปถามว่าจะบันทึกเป็นรายจ่ายไหม
- เปลี่ยนทริปเป็นต่างประเทศ แอปถามว่าจะเพิ่มของสำหรับต่างประเทศเข้าลิสต์ไหม

**ข้อมูล**
- สำรอง / กู้คืนเป็นไฟล์ `.json` (รวมเทมเพลตและรูปใบเสร็จ)
- ข้อมูลจาก TripBudget เวอร์ชันก่อนในเครื่องเดียวกันย้ายมาให้อัตโนมัติ และไฟล์สำรองแบบเก่ากู้คืนได้

## ไฟล์

```
index.html      ตัวแอปทั้งหมด (HTML + CSS + JS)
manifest.json   ข้อมูลสำหรับติดตั้งเป็นแอป
sw.js           Service worker สำหรับใช้งานออฟไลน์
icon.svg        ไอคอนแอป
icon-192.png    ไอคอนสำรองสำหรับ Android รุ่นที่ไม่รองรับ SVG
icon-512.png
```

## ติดตั้งบน Android

เปิดลิงก์ใน Chrome → เมนู ⋮ → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก** (หรือกด ⋮ ในแอป → 📲 ติดตั้งเป็นแอป)

## อัปเดตเวอร์ชัน

แก้ `index.html` แล้วเปลี่ยนเลขใน `sw.js` บรรทัด `const CACHE = 'tripbudget-v4.1.0'` ด้วย ผู้ใช้จะได้เวอร์ชันใหม่ตอนเปิดแอปครั้งถัดไป

## หมายเหตุ

- การล้างข้อมูลเว็บของ Chrome จะทำให้ข้อมูลหาย กด ⋮ → สำรองข้อมูล เป็นระยะ แล้วเก็บไฟล์ไว้ใน Google Drive
- เรทเงินเป็นเรทกลางตลาดจาก [ExchangeRate-API](https://www.exchangerate-api.com) เรทร้านแลกเงินจริงจะต่างเล็กน้อย
- เคล็ดลับและข้อมูลประเทศเป็นคำแนะนำทั่วไป กฎวีซ่าและสายการบินเปลี่ยนได้ ควรเช็กจากแหล่งทางการก่อนเดินทาง
