# ติดตั้งระบบรับความเห็นและสถิติ (Google Apps Script)

ทำครั้งเดียว ประมาณ 5 นาที ทำบนคอมพิวเตอร์จะง่ายกว่ามือถือ

## 1. สร้าง Google Sheet
1. เปิด https://sheets.new (ล็อกอิน Google ของคุณ)
2. ตั้งชื่อไฟล์ เช่น `TripBudget ความเห็น`

## 2. ใส่โค้ด
1. ในชีต กดเมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด
3. ก๊อปโค้ดจากไฟล์ `apps-script/Code.gs` ใน repo นี้ไปวาง แล้วกด 💾 บันทึก
4. (ไม่บังคับ) เลือกฟังก์ชัน `testFeedback` ด้านบน แล้วกด **Run** ครั้งแรกจะขอสิทธิ์ ให้กดอนุญาต
   - ถ้าขึ้น "Google hasn't verified this app" กด **Advanced → Go to ... (unsafe)** เพราะเป็นสคริปต์ของคุณเอง
   - กลับไปดูชีต จะมีแท็บ `Feedback` และแถวทดสอบ 1 แถว

## 3. เผยแพร่เป็น Web app
1. กด **Deploy → New deployment**
2. กดรูปเฟือง ⚙️ ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone** (ต้องเป็น Anyone เพื่อนถึงจะส่งได้โดยไม่ต้องล็อกอิน)
4. กด **Deploy** แล้วก๊อป **Web app URL** (ลงท้ายด้วย `/exec`)
5. เปิด URL นั้นในเบราว์เซอร์ ต้องเห็นข้อความ `TripBudget feedback endpoint OK`

## 4. ใส่ URL ในแอป
1. เปิดไฟล์ `version.js` ใน GitHub แล้วกด ✏️
2. วาง URL ใน `self.FEEDBACK_URL = '...';`
3. เปลี่ยนเลข `self.APP_VERSION` เป็นเลขถัดไป (เช่น `5.4.0` → `5.4.1`)
4. กด Commit — แอปของทุกคนจะขึ้นแถบ "มีอัปเดต" แล้วความเห็นที่ค้างอยู่ในเครื่องจะถูกส่งเข้ามา

## ถ้าแก้โค้ด Apps Script ภายหลัง
กด **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** URL เดิมใช้ต่อได้ ไม่ต้องแก้ในแอป

## ข้อมูลที่ได้รับ
- **Feedback**: ประเภท ข้อความ ชื่อเล่น (ถ้าใส่) เวอร์ชันแอป รุ่นเบราว์เซอร์ และข้อมูลทริปเฉพาะเมื่อผู้ใช้ติ๊กยินยอม
- **Usage**: วันที่ ชื่อหน้า/ปุ่ม และจำนวนครั้ง เช่น `v:budget` = เปิดหน้างบ, `a:saveQuick` = กดบันทึกเร็ว ไม่มีรหัสเครื่อง ยอดเงิน หรือชื่อรายการ
- **Errors**: ข้อความ error และตำแหน่งในโค้ด
